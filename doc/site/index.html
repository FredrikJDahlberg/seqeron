@VERSION@

seqeron assigns one global, gap-free, replicated total order to messages from external producers, using an Aeron Cluster (Raft) replicated state machine as the sequencer. Every node records the ordered stream, so a client reads it live off its own node and replays history from the same place.

This is the API reference for the client tier: what a producer or a consumer of the ordered stream programs against.

Java

The seqeron artifact on JitPack, with a BOM that pins Aeron, Agrona and SBE.

repositories { maven { url 'https://jitpack.io' } }
dependencies {
    implementation enforcedPlatform(
        'com.github.FredrikJDahlberg.seqeron:seqeron-bom:@TAG@')
    implementation 'com.github.FredrikJDahlberg.seqeron:seqeron'
}
Java API reference

C++

Header-only seqeron::seqeron_core, from FetchContent or an installed find_package(seqeron).

FetchContent_Declare(seqeron
    GIT_REPOSITORY https://github.com/FredrikJDahlberg/seqeron.git
    GIT_TAG        @TAG@)
FetchContent_MakeAvailable(seqeron)
target_link_libraries(my_app PRIVATE seqeron::seqeron_core)
